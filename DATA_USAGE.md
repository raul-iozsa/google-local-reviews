# Data provenance and release scope

The source is [Google Local Data (2021), UCSD McAuley Lab](https://mcauleylab.ucsd.edu/public_datasets/gdrive/googlelocal/).
The README lists the two papers the source page asks users to cite. The full
source archive, database credentials and local backups are not included here.

The repository includes aggregate results, selected review excerpts and the
475 unique reviews used in the 25-item pilot and 450-item main human audit.
The second-annotator sheet and the archived input snapshots repeat some of those
reviews. The texts are kept so the annotation calculations can be checked.
Business identifiers and project review identifiers are also present. Reviewer
account IDs have been removed, but verbatim review text is not anonymized.

The source page, checked on 4 October 2026, provides downloads and citation
instructions but does not state a license for redistributing review text, and
being publicly available and cited does not by itself grant that permission.
Redistribution rights for the included excerpts and annotation inputs are
therefore not confirmed.

No license has been assigned to the code or to the third-party review text. A
code license added later should cover the project's own code, not the source data.
